# Luật Việt Đức copy

Write for Vietnamese people dealing with life, family, documents, work or property between Vietnam and Germany. Help them understand where to start and what happens after an action. The main paths are the library and an ongoing conversation with AI or a specialist.

Use a calm, informed and human voice. Address visitors as “bạn”; use short action labels in admin. Prefer concrete situations to slogans. Keep a distinctive sentence when it earns its place; remove duplicate headings, filler, grand promises and instructions that merely describe obvious controls.

Keep the owner's approved brand, page structure and headline unless the request changes them. “Giải đáp pháp luật Việt Nam và Đức.” is the current homepage headline. “Thư viện”, “Tin tức”, “Giới thiệu” and “Đăng nhập” are established navigation labels. Don't introduce a new name for the same action on each page.

The product answers from eligible published knowledge. Missing evidence and individual cases can require a specialist. Don't invent response times, successful delivery, availability, legal approval, testimonials, affiliations or statistics. Distinguish a topic title from a published answer. Don't describe all data as private when some sources are public. Operational messages must match the actual saved, loading, failed or queued state.

For public pages, make each section useful: explain the visitor's situation, the help available or the next action. For errors, say what happened and give a real next step; network errors need retry, while expired sessions need sign-in. Use “Lưu thay đổi”, “Thử lại” and similarly specific labels. Keep technical connection instructions in admin, where they help configuration.

Write idiomatic German that communicates the same offer and limitations. Public navigation is bilingual; staff admin is Vietnamese. Keep the brand and personal names unchanged. Don't translate customer messages or published legal content without an authorized translation workflow. Read both versions at narrow widths; shorten copy rather than forcing fixed line breaks everywhere.

Before publishing, read the copy for clarity, tone, specificity, factual support and repetition. A useful question is whether every sentence helps the reader decide or act. For small edits, apply this directly without a research phase; for a broader rewrite, use the available Copywriting and Copy Editing skills as needed. Do not add approvals, publish content, install tools or contact anyone solely because this skill was invoked.
